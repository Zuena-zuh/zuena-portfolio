
# Zuena — Developer Portfolio

A personal developer portfolio built with React and Vite, showcasing my projects, technical skills, and journey as an aspiring software developer.

## About

This portfolio brings together my work, interests, and experience in software development. It is designed to provide a simple way to explore my projects and get in touch.

## Features

- Responsive design for desktop and mobile
- Multiple pages with React Router
- Interactive project cards and project details
- Contact form powered by Formspree
- Dark and light theme toggle
- Custom 404 page
- Navigation with active page highlighting

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate into the project folder:

   ```bash
   cd zuena-portfolio
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
